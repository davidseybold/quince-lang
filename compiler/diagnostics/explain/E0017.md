# E0017: a bracket that is never closed

An opening `(`, `[` or `{` has no matching closing bracket. The error is at the opening bracket.

```
fn f() {
  let a = g(1, 2
  let b = 3
}

fn h() {
  let c = 4

fn k() {}
```

The parser notices when it reaches something that can't be inside the bracket: here a `let` line, which starts a statement and can't be an argument, and a `fn` line, which starts a declaration and can't be in a block (`grammar.block`). It closes the bracket there, so the code after it is still checked. Add the closing bracket where it belongs:

```
fn f() {
  let a = g(1, 2)
  let b = 3
}

fn h() {
  let c = 4
}

fn k() {}
```

A closing bracket that matches one further out closes the brackets inside it, with this error at each. The end of the file closes every open bracket. There is no fix, because only the author knows where the bracket ends.

When the parser has already reported an error and is skipping to a line break or a `,`, a bracket it closes gets no error, since the first error covers that mistake. Once it is fixed, the missing bracket shows.
