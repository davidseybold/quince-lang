# E0005: an unclosed multi-line string

A multi-line string sits between `"""` lines (`r[lex.lit.string.multiline]`), and it ends at the first `"""` an escape doesn't take (`r[lex.lit.multiline-quotes]`). One with no such quotes after its opening `"""` runs to the end of the file.

```
fn f() -> String {
  let usage = """
    quince build
    quince test
  usage
}
```

End it with a line that starts with `"""` after its indentation:

```
fn f() -> String {
  let usage = """
    quince build
    quince test
    """
  usage
}
```

There is no fix, because the lexer can't tell where the string was meant to end. Since the rest of the file is probably code, not text, it isn't checked for escapes or interpolation, so one missing line doesn't bring an error for every backslash and brace after it.

Quotes after text, as in `quince test"""`, end the string too, but they are an E0012, not this error.
