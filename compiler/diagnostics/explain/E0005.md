# E0005: an unclosed multi-line string

A multi-line string sits between `"""` lines (`r[lex.lit.string.multiline]`), and it ends at the first line that starts with `"""` after its indentation (`r[lex.lit.multiline-close]`). One with no such line runs to the end of the file.

```
fn f() -> String {
  let usage = """
    quince build
    quince test"""
  usage
}
```

A `"""` after other text on its line is text, so this string never ends. Put the closing `"""` on a line of its own:

```
fn f() -> String {
  let usage = """
    quince build
    quince test
    """
  usage
}
```

There is no fix, because the lexer can't tell where the string was meant to end. Since the rest of the file is probably code, not text, it isn't checked for escapes or interpolation, so one missing line doesn't bring an error for every backslash and brace after it.
