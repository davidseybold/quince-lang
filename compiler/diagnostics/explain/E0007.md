# E0007: an interpolation that isn't a path

Inside a string's braces, only a path is allowed (`r[lex.lit.string.interp-root]`): a name, `self` or a constant name, followed by any number of field names or tuple positions, with no spaces. Not an expression, a method call, a format specifier or a type.

```
fn f(user: User, total: Float) {
  let a = "{user.name.len()} chars"
  let b = "Total: {total:.2}"
  let c = "{ user.name }"
  let d = "{}"
}
```

Bind an expression with `let` first, and write its name in the braces. A literal brace is written `\{`:

```
fn f(user: User, total: Float) {
  let length = user.name.len()
  let a = "{length} chars"
  let price = total.to_fixed(2)
  let b = "Total: {price}"
  let c = "{user.name}"
  let d = "\{}"
}
```

A path can't start with a type, as in `{Self.MAX}`: bind the value first. The lexer knows only that `Self` is a type, so name resolution reports a path that starts with any other type name.

When the braces hold a path with spaces around it or around its dots, the fix deletes the spaces. The other forms have no fix, because the name to bind is the author's choice. A `{` that is never closed ends at the next `"` or line end, so the string still ends at its closing quote.
