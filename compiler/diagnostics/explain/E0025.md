# E0025: `{}` where an expression is expected

`{` where an expression is expected starts a map literal (`r[expr.block.brace-map]`), and the empty map is written `{:}` (`r[lex.lit.empty-map]`). There are no bare blocks (`r[expr.block.no-bare]`), so `{}` is neither an empty block nor the unit value:

```
let seen = {}
```

Write the empty map:

```
let seen = {:}
```

The fix inserts the `:`. It needs review, since you may have meant something else: the unit value is `()`, and an empty list is `[]`.
