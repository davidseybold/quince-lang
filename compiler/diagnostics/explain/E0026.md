# E0026: an assignment whose left side isn't a place

Assignment writes a value to a place (`r[stmt.assign.stmt]`). A place is a `var` binding, a field path from one, or an index into one (`r[stmt.assign.place]`). It is written as a name or `self`, followed by fields, tuple positions and indexes, such as `total`, `user.address.city`, `pair.0` or `grid[i][0]`. Anything else on the left of `=` or a compound assignment is an error:

```
xs.len() = 0
(total) = 3
```

A call, an operator, `?` or parentheses gives a value, not a place, so it can't be assigned. Assign to the binding or field the value comes from:

```
xs = []
total = 3
```

There is no fix, since only you know which place was meant.
