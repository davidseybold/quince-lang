# E0027: `()` where a type is expected

`Unit` is the type with exactly one value, `()`, and the type is written `Unit`, never `()` (`r[type.unit]`). So there is one way to write it, and `()` where a type goes is an error:

```
fn save(order: Order) -> Result<(), DbError> uses Db {
  db.insert(order)
}
```

Write `Unit`:

```
fn save(order: Order) -> Result<Unit, DbError> uses Db {
  db.insert(order)
}
```

The fix writes it. It needs review, since a type or a type parameter of your own named `Unit` would take its place. There is no fix when anything but spaces lies between the parentheses, such as a comment, since replacing them would delete it.
