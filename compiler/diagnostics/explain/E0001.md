# E0001: a character that starts no token

Outside string literals, char literals and comments, Quince source is ASCII (`r[lex.source.ascii]`), and spaces and tabs are its only whitespace within a line (`r[lex.source.whitespace]`). This error is a character that can't start any token there: `$`, `#`, a backtick, a backslash, a control character, a byte order mark after the start of the file, or any non-ASCII character, such as `é` or a no-break space. A run of such characters is one error.

```
let café = 1      # a price
```

Names use ASCII letters, digits and `_`, and comments start with `//`:

```
let cafe = 1      // a price
```

- Strings use `"`, not backticks, and interpolate with `{name}`.
- Raw text that holds quotes is written `r"""`, not `r#"`.
- A Unicode space such as U+00A0 has a fix that replaces it with a space.
