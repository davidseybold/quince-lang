# E0011: a non-ASCII character in a bytes literal

A bytes literal holds ASCII characters, `\x` escapes and the escapes `\n`, `\r`, `\t`, `\0`, `\\` and `\"` (`r[lex.lit.bytes]`). A character outside ASCII has no single byte, so it is an error.

```
fn f() -> Bytes {
  b"café"
}
```

Write it as the `\x` escapes of its UTF-8 bytes:

```
fn f() -> Bytes {
  b"caf\xC3\xA9"
}
```

A run of non-ASCII characters is one error. The fix writes the escapes in their place and is safe, since the literal's bytes stay the same. A `\` right before a non-ASCII character is an invalid escape instead, which E0006 reports, and so is a `\u{...}` escape, which bytes literals don't take.
