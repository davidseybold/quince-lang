# E0002: a semicolon

A statement ends at its line break, so Quince has no `;` (`r[lex.braces]`).

```
fn f() {
  let a = 1;
  let b = 2; let c = 3
}
```

Delete a `;` at the end of a line, and put each statement on a line of its own:

```
fn f() {
  let a = 1
  let b = 2
  let c = 3
}
```

The fix deletes a `;` that ends a line. A `;` between two statements has no fix, because the line break that replaces it needs the line's indentation.

A `;` ends its statement even when the next line starts with `.`, so `a;` followed by a line `.b()` is two statements. Deleting that `;` makes one, `a.b()` (`r[lex.continue.more]`), so there the fix needs review.
