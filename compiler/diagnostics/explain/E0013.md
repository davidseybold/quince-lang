# E0013: a carriage return without a line feed

A line ends at a line feed (LF), or at a carriage return followed by a line feed (CR LF). A carriage return anywhere else is an error (`r[lex.source.line-end]`). A lone CR is almost always damage from a tool that mixed up line endings. It still ends its line, so the positions of later errors stay right, but the file doesn't compile.

The fix replaces the CR with an LF. `quince fmt` writes every line ending as an LF (`r[lex.source.canonical]`).

When the CR ends a string or char literal that has no closing quote, there is no fix: with an LF there, the literal would still be unclosed. When the CR follows another CR, there is no fix either: an LF after a CR makes one CR LF line ending, so two lines would become one.
