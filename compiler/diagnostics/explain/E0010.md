# E0010: an unknown literal tag

A name glued to a `"` is a literal's prefix. `r"` starts a raw string and `b"` a bytes literal, and the tags of tagged literals are a fixed set (`r[lex.lit.tagged]`): `url`, `re`, `dur` and `ts`. Any other name glued to a quote is an error. A keyword is never a prefix, so `test"adds"` is a test.

```
fn f(name: String) -> String {
  f"hello {name}"
}
```

Every `"` string interpolates already, so the `f` isn't needed:

```
fn f(name: String) -> String {
  "hello {name}"
}
```

The same error appears when a quote inside a string isn't escaped. In `"say "hi" now"`, the string ends at the quote before `hi`, and `hi"` reads as a tag. Write the inner quotes as `\"`: `"say \"hi\" now"`.

Only `"""` and `r"""` are multi-line (`r[lex.lit.multiline-forms]`), so `b"""` and a tag before `"""` are this error too. Write a bytes literal on one line, with `\n` for each line break, and a tagged literal on one line.

The literal after an unknown tag is read as a tagged literal, whose body is raw, so it reports nothing else, not even a missing closing quote. A `b"""` or tagged `"""` literal is read to its closing `"""` line, as an `r"""` string is, so that line doesn't open a new string. There is no fix, since the lexer can't tell which literal was meant.
