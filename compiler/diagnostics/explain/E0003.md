# E0003: a block comment

Quince has only `//` line comments (`r[lex.comment.line]`). A `/* */` comment breaks easily under partial edits: deleting one end of it changes the meaning of every line after it.

```
/* Retries a request.
   Gives up after three tries. */
fn retry() {}
```

Write each line as a `//` comment:

```
// Retries a request.
// Gives up after three tries.
fn retry() {}
```

When the comment covers whole lines, the fix rewrites it as `//` lines. A `/*` that is never closed runs to the end of the file, so nothing after it is checked until it is fixed.
