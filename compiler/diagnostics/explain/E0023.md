# E0023: a doc comment that documents nothing

A `///` doc comment documents the declaration, field, variant or member after it, and must come right before one (`r[lex.comment.doc-placement]`). Doc comments come before a declaration's attributes, and one after code on its line documents nothing (`r[lex.comment.doc]`). A doc comment anywhere else would be lost quietly, so it is an error:

```
fn total(xs: List<Int>) -> Int {
  /// Sum the items.
  xs.sum()
}
```

Make it an ordinary comment:

```
fn total(xs: List<Int>) -> Int {
  // Sum the items.
  xs.sum()
}
```

Or move it above what it documents. The fix makes it an ordinary comment, safely, and one error covers the doc comments that come together before the same code.
