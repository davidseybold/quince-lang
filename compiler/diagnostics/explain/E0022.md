# E0022: code that nests deeper than the parser's limit

The compiler reads code into a tree, and limits how deep the tree may go, so that no input can exhaust its stack. Each nested expression, block, type and pattern is a level, and so is each step of a chain of operators or calls: a method call is two, its field and its call. The limit is 256 levels, which hand-written code doesn't come near. Generated code can:

```
let total = a + b + c + d + ... // hundreds of terms on one line
```

Split the code into bindings or functions, so no part of it nests as deep:

```
let first = a + b + c + d + ...
let second = ...
let total = first + second
```

The error is at the token that goes past the limit. The rest of its line, or of the brackets it is in, is skipped, so nothing in it is checked until the error is fixed. There is no fix, because only the author knows where to split the code.
