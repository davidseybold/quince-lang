# E0008: a malformed number

A number literal doesn't have one of the forms in the spec's Literals section:

- An underscore sits only between two digits (`r[lex.lit.underscore]`): `1_000`, not `1_`, `1__0`, `0x_FF` or `1_.5`.
- A base prefix is lowercase and has digits of its base after it (`r[lex.lit.int.prefix]`, `r[lex.lit.int.forms]`): `0xFF`, not `0XFF`, `0x` or `0b102`.
- A decimal number starts with `0` only when its integer part is `0` (`r[lex.lit.int.leading-zero]`): `0.5`, not `007` or `00.5`. Quince has no C-style octal; write `0o17`.
- An exponent is a lowercase `e`, an optional sign and digits (`r[lex.lit.float.shape]`): `1e9`, not `1E9` or `1e`.
- A number has no type suffix (`r[lex.lit.no-suffix]`): its type comes from context.

```
fn f() {
  let a = 1u8
  let b = 1E9
  let c = 007
}
```

```
fn f() {
  let a: UInt8 = 1
  let b = 1e9
  let c = 7
}
```

The fix lowercases an uppercase prefix or `E`. For a suffix, the fix removes it and needs review, since the type it named now has to come from context, such as a type on the `let`. The other forms have no fix, because only the author knows the intended digits.
