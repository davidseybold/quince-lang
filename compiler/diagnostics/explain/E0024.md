# E0024: a struct with no fields written with braces

A struct with no fields is declared without braces, and its one value is written as its name (`r[item.struct.no-fields]`). So there is one way to write it, and `{}` is an error:

```
pub struct ChannelClosed {}
```

Remove the braces:

```
pub struct ChannelClosed
```

The fix removes them, safely. When a `requires` follows the braces there is no fix, since a struct with no fields has nothing for a condition to check: remove the `requires` too.
